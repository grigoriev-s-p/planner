# PostCode product frontend

Статический интерфейс из исходного прототипа v7: vanilla HTML, CSS и JavaScript
без npm и build pipeline. Layout, шесть страниц, навигация, sprint board,
фильтры и карточки сохранены. Данные загружаются из FastAPI через `api.js`.

## Запуск

Запускайте из корня проекта после preprocessing:

```powershell
python -m uvicorn src.web.api:app --reload
```

Откройте `http://127.0.0.1:8000`. Открытие `index.html` как локального файла не
поддерживается: интерфейсу нужен API того же приложения.

## Файлы

- `index.html` — структура шести страниц и статические подписи;
- `styles.css` — исходный внешний вид и адаптивная вёрстка;
- `api.js` — единый клиент `/api/*`;
- `app.js` — отдельные UI state, server data и функции отображения.

## Источники данных

«Главная», «Планирование», «Задачи», «Риски» и «Звёздная карта» показывают
processed dataset и результат текущего quarter planner. Frontend не вычисляет
capacity, feasibility, приоритеты, зависимости, риски или рекомендации.

Страница «Пересчёт плана» остаётся интерфейсной заготовкой, потому что backend
replanning пока отсутствует. Выбор файла не обрабатывает его. Bus Factor также
помечен как не рассчитанный и не подменяется frontend-алгоритмом.
